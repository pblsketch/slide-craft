# 시각 방향과 장면 선택

스타일은 수업 목적이 아닌 시각적 특징으로 구분하며 여러 주제와 청중에 적용할 수 있다. 아래 방향은 예시이며 목록 밖 스타일도 가능하다. 스타일 이름을 선언하는 데 그치지 말고 실제 글자·간격·색·구도에 반영한다.

| 디자인 스타일 | 시각적 특징 | 장면 구성 판단 |
|---|---|---|
| Bold Typography | 큰 핵심 문장, 강한 명암 대비, 적은 강조색 | 한 장의 중심 문장이 즉시 읽히는가 |
| Swiss Grid | 정렬된 그리드, 산세리프, 큰 숫자와 여백 | 문장·숫자·그림의 위계가 배치로 드러나는가 |
| Warm Minimal | 크림색·갈색, 얇은 선, 세리프 인용과 넓은 여백 | 작은 글자나 낮은 대비로 가독성을 해치지 않는가 |
| Editorial | 잡지형 구도, 제목과 본문의 크기 대비, 이미지와 캡션 | 내용에 맞게 비대칭과 여백을 활용하는가 |
| Duotone | 두 가지 주요 색과 선명한 면 분할 | 색의 대비가 비교 관계나 핵심 메시지에 기여하는가 |
| Collage | 사진·문서·메모를 조합한 다층 구도 | 시각적 질감이 내용과 연결되고 읽는 순서가 분명한가 |
| Duotone Split | 두 색의 큰 면 분할, 대칭 또는 비대칭 비교 | 양쪽 개념이 같은 기준으로 읽히고 글의 대비가 충분한가 |
| Editorial Magazine | 비대칭 제목·삽화, 종이색, 크기가 다른 글 | 삽화가 메시지를 설명하고 장마다 구도가 달라지는가 |

필요하면 스타일을 섞는다. Editorial Magazine의 제목·삽화 구도와 Swiss Grid의 정렬을 결합하거나, 비교 장면에만 Duotone Split을 적용할 수 있다. 목록은 선택 가능한 전부가 아니며 사용자가 제시한 시각 방향을 우선한다.

같은 주제라도 청중·발표 목적·원하는 분위기에 따라 다른 구도를 쓸 수 있다. 기존 덱의 카드 배치를 유지한 채 색만 바꾸지 않는다.

제목이나 상자의 위쪽·왼쪽에 장식용 강조선을 붙이지 않는다. 색·글자 크기·여백으로 구분하며, 표 테두리와 그래프 축처럼 기능이 있는 선은 유지한다. 표의 짧은 제목·항목·숫자는 가운데 정렬을 검토하고 긴 설명은 왼쪽 정렬한다.

## 덱 전체와 한 장의 균형

- 스타일의 차이는 색뿐 아니라 구도, 글자 크기의 대비, 여백의 위치, 이미지·도식의 역할로 드러낸다. 사례를 바꾸면서 같은 카드 세 개만 반복하지 않는다.
- 한글 제목의 글꼴·굵기·자간과 줄바꿈을 직접 다듬는다. 글꼴을 포함할 때는 이용 조건과 고지를 지킨다. 표지의 큰 문구, 자료를 보는 장면, 설명 도식, 참여 안내는 각 역할에 맞게 디자인한다.

- 덱은 서체·색·간격의 기준을 공유한다. 각 장은 내용에 맞는 구도를 선택한다.
- 도입, 설명, 자료 읽기, 활동 안내, 마무리는 서로 다른 시각적 리듬을 가질 수 있다. 모든 장에 상자 세 개를 배치하는 식으로 통일하지 않는다.
- 사진이 핵심이면 사진이 충분히 크게 보여야 한다. 설명을 위한 차트라면 장식보다 값·단위·비교 관계가 읽혀야 한다.
- 제목은 ‘내용 요약’ 또는 ‘참여자가 생각할 질문’ 역할을 한다. 글이 많아지면 먼저 장의 역할을 분리한다.
- 수업 활동 안내에는 무엇을, 누구와, 어떤 결과물로 남길지 드러낸다. 필요하지 않은 시간표·단계 표식을 모든 장에 붙이지 않는다.

## 화면과 출력

화면 비율과 크기는 상황에 맞게 정한다. HTML의 `aspect-ratio`, 그리드, 비례 축소 등을 적절히 사용하되 좁은 화면에서 텍스트가 겹치거나 사라지지 않는지 확인한다. 발표 보기는 도구 모음의 ‘발표 보기’와 장 이동을 활용할 수 있다.

PDF가 필요할 때만 페이지 크기와 장별 쪽 나눔을 정한다. 인쇄 때 편집 도구는 사라지지만 내용은 모두 남아야 한다. ‘교사용’이나 ‘배포 금지’ 표시를 자동으로 붙이지 않는다.

## Additional reference directions

| Style | Visual grammar | Adaptation |
|---|---|---|
| Pin & Paper | Yellow paper, ink blue, loose memo placement | Use notes as real observation or response areas; omit ornamental pins and binder holes. |
| Cobalt Grid | Cobalt typography, precise grid, editorial hierarchy | Use actual mathematical grids and calculated coordinates; omit pixel ornaments and accent rules. |
| Grove | Forest green, cream, classical serif hierarchy | Keep worksheet writing areas light; mix dark and light presentation scenes. |
| Notebook Tabs | Paper page, coloured section tabs | Label actual sections; make screen tabs navigate when appropriate. |
| Retro Zine | Beige paper, saturated green, oversized print-like type | Vary source, headline and draft space; preserve readability and actual response space. |
| Sakura Chroma | Cream paper, retro multicolour palette, geometric motifs | Use colours to distinguish real categories; use an illustration only when it relates to content. |

These directions can be combined or replaced by a user reference. They are not a closed preset list, required palette or fixed layout. Centre short table labels and numerical entries where appropriate. Keep explanatory text left-aligned. Do not add decorative top or left accent rules.
