# 수식·그래프·도형을 수업 자료에 넣기

수식과 그래프도 HTML의 구성 재료다. 국어형 문단·표에 자료를 억지로 맞추지 않는다. 필요한 관계를 정확하게 보여 주고, 학생이 계산하거나 직접 그릴 공간을 별도로 확보한다.

## 수식

1. 식과 변수의 뜻을 먼저 확인한다. 분수의 분자·분모, 지수, 괄호 범위를 명확히 한다. 원자료에 없는 식을 인용으로 표시하지 않는다.
2. 편집할 수식은 `data-math` 요소의 `data-latex`에 LaTeX 원문을 기록한다. 동봉된 KaTeX가 렌더하며, 필요한 JS·CSS·글꼴·라이선스는 연결 스크립트가 HTML 안에 포함한다. CDN이나 별도 Node 설치 없이 완성 파일에서 수식을 고칠 수 있다.
3. `data-display="inline"`은 문장 안, `data-display="block"`은 별도 줄이다. `data-math` 내부에 `data-edit`를 붙이지 않는다. 주변 문장만 `data-edit`로 표시한다. 렌더된 내부 DOM을 직접 고치는 대신 수식 편집창을 사용한다.
4. 글 안의 식과 별행 수식의 기준선, 분수 높이, 한글과 수식의 간격을 화면과 PDF에서 확인한다. 설명·문항·풀이 공간은 따로 편집할 수 있게 한다.

```html
<figure data-piece>
  <span data-math data-latex="y=\frac{1}{2}x+1" data-display="block"></span>
  <figcaption data-edit>기울기와 y절편을 읽어 봅시다.</figcaption>
</figure>
<p data-edit>속력은 <span data-math data-latex="v=\frac{s}{t}"
  data-display="inline"></span>로 나타냅니다.</p>
```

수식을 클릭하거나 초점을 두고 Enter를 누르면 원문·미리보기·적용·취소 창이 열린다. 분수·근호·위첨자·아래첨자 버튼과 펼쳐 보는 연립식·행렬·합·적분·벡터·여러 줄 풀이 버튼이 있다. 오류가 있으면 적용하지 않고 원본을 보존한다. 적용은 되돌리기·다시 하기에 포함되고 원문과 렌더 결과는 HTML에 함께 저장된다. 새 수식은 `추가 → 수식`에서 넣는다. 문장 안에 넣을 때는 글에서 삽입 위치를 먼저 선택한다.

LaTeX 원문에는 `$`나 `$$` 구분자를 붙이지 않는다. HTML 속성에 들어가는 따옴표·앰퍼샌드는 이스케이프한다. 미리보기 초안은 적용 전까지 문서에 저장되지 않는다. 명시적으로 연결한 함수 그래프는 수식 변경과 함께 갱신된다. 기존 임의의 SVG나 이미지 그래프는 자동 연결하지 않는다. 기존 일반 텍스트·임의의 MathML은 자동 변환하지 않으므로 원식을 확인해 `data-math`로 옮긴다. 이 편집기는 KaTeX 지원 명령을 사용하며 모든 LaTeX 패키지를 실행하는 환경은 아니다.

## 함수 그래프와 좌표평면

1. 정의역·치역, 축 이름, 단위, 눈금 간격, 원점과 주요 좌표를 정한다. 학생이 그려야 할 그래프와 이미 보여 줄 그래프를 구분한다.
2. SVG `viewBox` 안에 모눈, 축, 눈금, 곡선, 주석을 각각 작성한다. 이미지 생성 모델로 정확한 좌표나 곡선을 그리게 하지 않는다.
3. 수학 좌표를 화면 좌표로 변환한다. 예를 들어 `px = left + (x-xmin)/(xmax-xmin)*width`, `py = top + (ymax-y)/(ymax-ymin)*height`. y축 방향은 반대다.
4. 곡선은 식에서 계산한 좌표로 그린다. 그래프 영역 밖은 clipPath로 자르고, 불연속점은 선을 끊는다. 빈 좌표평면에는 학생이 그릴 답을 미리 표시하지 않는다.
5. 식에 대표 x값을 대입해 그래프의 점과 일치하는지 검사한다. 가로·세로 단위 길이가 다르면 각도나 기울기의 시각적 인상이 달라짐을 고려한다. 기하 문제는 동일 축척을 사용한다.

원식, 데이터, 축 범위를 HTML의 JSON 또는 `data-*`에 남긴다. SVG는 확대·인쇄해도 선명하며 주변 질문·답란과 함께 복제·이동할 수 있다. 연결 함수는 수식 편집창에서, 연결 통계 그래프는 원자료 표에서 고친다. 임의의 도형 내부 점은 별도 편집이 필요하다.

## 통계 그래프·과학 도식

수학은 학년·단원·차시 목표를 먼저 정하고, 수식·도형·좌표평면은 그 목표에 필요할 때 사용한다. 같은 단원의 기초 확인, 안내가 있는 핵심 유형, 독립 적용, 검산으로 이어지는 흐름을 검토한다. 시각 요소를 보여 주기 위해 다른 단원의 문제를 무작정 섞지 않는다. 과학 실험지는 준비물·장치·절차, 바꿀 조건과 같게 할 조건, 반복 측정의 단위, 결과 해석을 연결한다. 자료 분석지는 원자료와 그래프를 함께 제시하고 수치 확인, 근거 기반 설명, 추가로 확인할 질문을 구분한다.

- 막대·꺾은선·산점도에는 변수, 단위, 기준선, 범례와 출처를 표시한다. 막대 길이와 점의 위치는 실제 값으로 계산한다. 가상 자료라면 그래프 근처에 밝힌다.
- 실험 장치·힘의 방향·회로·기하 도형은 필요한 구조를 정확한 SVG로 그린다. 의미 있는 색과 라벨을 함께 써서 색만으로 구별하지 않게 한다.
- 큰 그래프 옆에는 짧은 관찰 질문, 아래에는 계산·설명 공간을 둘 수 있다. 모든 수학 문제를 작은 표 셀 안에 넣지 않는다.
- 화면에서 수정·복제·저장·재열기 뒤에도 수식, SVG, 원식·데이터가 함께 남는지 확인한다. PDF에서는 분수선, 지수, 눈금, 얇은 모눈과 답란을 실제 크기로 본다.

## 자동 연동 연결 방법

1. 함수 연동이 필요하면 다음 그룹을 작성한다. 그룹에는 `data-math`가 정확히 하나 있어야 한다. 캔버스는 편집기가 생성한다. 기존 SVG를 이 그룹 안에 그대로 중복해서 넣지 않는다.

```html
<section data-piece data-function-graph
  data-graph-config='{"xmin":-5,"xmax":5,"ymin":-5,"ymax":8,"parameters":{"a":1,"b":0,"c":0}}'>
  <span data-math data-display="block" data-latex="y=a x^2+b x+c"></span>
</section>
```

2. 함수 수식은 y= 또는 f(x)= 형태를 지원한다. x와 계수 a,b,c,k, pi,e, 사칙연산, ^, 괄호, 암시적 곱셈, LaTeX 분수·제곱근, sin/cos/tan/sqrt/abs/exp/ln/log를 쓴다. 함수 인수는 괄호로 묶는다. 삼각함수는 라디안, log는 상용로그다. 임의 코드 실행이나 기호 대수 계산은 하지 않는다. 수치 샘플링이므로 급격한 진동·불연속 함수는 실제 그래프를 별도 점검한다.
3. 표와 연동하려면 다음처럼 작성한다. 첫 열은 항목, 이후 1~4열은 수치 계열이며 머리글과 최대 30개의 자료 행을 지원한다. 병합 셀과 빈 수치는 허용하지 않는다. 꺾은선의 첫 열이 모두 수치이면 증가 순서로 작성하고 실제 x 간격을 사용한다.

```html
<section data-piece data-data-chart data-chart-type="bar"
  data-chart-x-label="시간 (분)" data-chart-y-label="온도 (°C)">
  <table data-chart-table>
    <thead><tr><th data-edit>시간</th><th data-edit>온도</th></tr></thead>
    <tbody><tr><td data-edit>0</td><td data-edit>20</td></tr>
    <tr><td data-edit>2</td><td data-edit>35</td></tr></tbody>
  </table>
</section>
```

4. 편집기 연결 후 함수 원문과 계수, 표의 값을 바꾼다. 적용·취소·되돌리기, 저장 후 오프라인 재열기를 확인한다. 잘못된 식·범위는 적용할 수 없다. 잘못된 표는 오류를 표시하며 저장·출력 버튼을 막는다. 브라우저에서 직접 인쇄해도 오류가 있는 예전 그래프를 숨긴다.
5. 그래프 영역의 크기는 자료의 HTML/CSS로 정하고 실제 지면에서 확인한다. 빈 좌표평면, 기하 도형, 이미지는 이 연결 기능과 별도로 유지한다.
