# 디자인에 편집 기능 연결하기

HTML/CSS가 디자인을 소유한다. 편집 도구는 별도의 시각 템플릿이나 블록 스키마를 요구하지 않는다.

## 최소 표시

```html
<main data-teach-document>
  <section data-piece class="내가-정한-디자인">
    <h1 data-edit>자유롭게 구성한 제목</h1>
    <p data-edit>수정 가능한 설명</p>
  </section>
  <section data-piece>
    <table>
      <thead><tr><th data-edit>관찰 항목</th><th data-edit>기록</th></tr></thead>
      <tbody><tr><td data-edit>첫 번째 관찰</td><td data-edit></td></tr></tbody>
    </table>
  </section>
</main>
```

- `data-teach-document`: 본문 컨테이너 하나. 없으면 단 하나의 `main`을 사용한다.
- `data-edit`: 수정할 제목·문단·라벨·표 셀·빈 답란. **표 전체나 문서 전체에 붙이지 않는다.** 내용 요소마다 붙이면 셀에서 전체 선택해도 표 구조가 지워지지 않는다. SVG·수식 내부처럼 직접 글을 입력하면 깨지는 곳에는 붙이지 않는다.
- `data-piece`: 복제·이동·삭제할 범위. 질문과 답란을 함께 옮기려면 같은 범위에 둔다. 중첩이나 요소 종류를 제한하는 규격이 아니다.
- `data-slide`: 슬라이드 한 장. 편집 모드에서는 전체 장을 볼 수 있고, 발표 모드에서는 선택한 장을 표시한다. 장의 폭·비율·배치는 문서 CSS로 정한다.
- `data-answer-space`: 높이·괘선 수·간격을 조절할 답란. 보통 `data-edit`와 함께 `div`에 붙인다. 표 안이라면 셀 안쪽 응답 영역에 붙인다. 기존 괘선이 있으면 `data-answer-lines="3" data-answer-pitch="7.5"`처럼 줄 수와 간격(mm)을 기록한다.
- `data-math` + `data-latex`: KaTeX로 표시하고 클릭해 편집할 수식. `data-display`는 `inline` 또는 `block`이다. 수식 내부는 직접 글 편집에서 보호한다. 자세한 연결 예시는 [수식과 그래프](math-and-graphs.md)를 참고한다.

수정할 글은 빠짐없이 표시한다. 출처·설명·표 머리·활동 번호도 고칠 수 있어야 한다. 브라우저 입력창이나 체크박스를 쓰는 문서는 그 현재 값도 HTML 저장에 포함된다.

복제할 영역의 디자인은 재사용 가능한 class 선택자로 작성한다. 특수 인터랙션은 이벤트 위임 등으로 연결하고, 복제·되돌리기 뒤에도 실제로 동작하는지 확인한다.

## 연결 명령

```text
python scripts/attach_editor.py 초안.html --output 완성.html --kind worksheet
python scripts/attach_editor.py 초안.html --output 발표.html --kind slides
```

경로는 스킬 폴더 기준이다. 다른 폴더에서 실행하면 스크립트의 절대 경로를 쓴다. 출력 파일이 이미 있으면 기본적으로 중단한다. 의도한 교체에만 `--overwrite`를 쓴다. 이미 연결한 HTML의 내용은 직접 수정한다. 편집 기능 자체를 새 버전으로 갱신할 때는 원본을 보존하고 다음처럼 새 파일을 만든다.

```text
python scripts/attach_editor.py 기존.html --output 편집기갱신.html --kind worksheet --refresh-editor
```

갱신은 도구가 소유한 편집 자원만 바꾸며 본문과 디자인은 보존한다. 다른 방식으로 만든 편집기를 임의로 제거하지 않는다.

편집 자원은 파일 안에 들어간다. 설치 폴더의 위치가 달라도 생성한 파일은 브라우저만으로 열린다. 외부·상대 경로의 이미지/스타일은 먼저 포함해야 한다. 일반적인 출처 링크는 콘텐츠를 불러오는 의존성이 아니므로 허용한다.

## 화면·인쇄 CSS

시각 디자인은 본문 컨테이너 안에 적용한다. 도구 모음까지 영향을 받는 전역 `section`, `button`, `aside` 선택자는 가능한 한 본문 범위로 좁힌다. 도구 모음은 화면에서 본문 앞에 나타나며 인쇄에서는 숨겨진다.

종이용 활동지는 화면과 인쇄의 본문 폭을 일치시킨다. 예를 들어 A4에 좌우 12mm를 쓰면 본문은 186mm다. 쪽 수를 강제로 고정하는 높이·overflow로 긴 내용을 잘라 내지 않는다. 별도 쪽 컨테이너는 필요할 때만 만들고 내용이 늘면 흐르게 한다.

슬라이드의 예:

```css
[data-teach-document] { max-width: 1200px; margin: auto; }
[data-slide] { aspect-ratio: 16 / 9; padding: 4%; margin: 24px 0; }
@media print {
  @page { size: 297mm 167.0625mm; margin: 0; }
  [data-slide] { width: 297mm; height: 167.0625mm; margin: 0; break-after: page; }
}
```

이 값은 예시다. 세로 슬라이드·다른 비율·별도 유인물이 필요하면 바꾼다. 화면과 출력에서 직접 넘침을 확인한다.

## 동작과 한계

- 상단에는 추가·되돌리기·미리보기·저장·인쇄가 있다. 글·셀·이미지·답란을 누르면 관련 설정만 나타난다. 도구를 접어 지면을 넓게 볼 수도 있다.
- 글은 굵게·기울임·밑줄, 크기(pt), 글꼴, 정렬, 줄 간격(배), 색을 고친다. 부분 선택의 서식과 글 영역 전체의 서식을 구분한다.
- 표는 선택한 셀을 기준으로 행·열을 추가·삭제하고, 열 너비(%)와 행 높이(mm)를 조절한다. 내용이 있는 행·열은 삭제 전 확인한다. 병합된 표는 내용·서식·행 높이 편집만 지원하며, 구조 변경과 열 너비 조절은 제한한다.
- 답란은 높이(mm), 괘선 수, 줄 간격(mm)을 바꾼다. 내용이 늘어나면 잘리지 않도록 필요한 높이를 유지한다.
- 이미지 추가는 PNG/JPEG/WebP/GIF 파일을 내부 데이터로 포함한다. 이미지 선택 후 교체, 비율을 유지하는 너비 조절, 설명 수정을 할 수 있다.
- 슬라이드는 선택 영역의 ‘이동’ 손잡이와 모서리 손잡이로 이동·크기 조절을 한다. 손잡이에 초점을 두고 방향키로 1px, Shift+방향키로 10px씩 조절할 수 있다. 끌던 중 Escape로 취소한다. 기존 회전은 유지한다. 슬라이드 밖으로 나간 내용은 안내를 보고 조정한다.
- 되돌리기는 현재 탭의 최근 편집을 기억한다. 파일에 히스토리나 자동 백업을 숨겨 넣지 않는다.
- `HTML 저장`은 새 파일 다운로드다. 기존 파일을 조용히 덮어쓰거나 별도 ‘학생본’을 생성하지 않는다. 저장한 결과에서도 계속 편집한다.
- 수식은 클릭하거나 `추가 → 수식`으로 연다. LaTeX 원문, 자주 쓰는 수식 버튼, 즉시 미리보기, 적용·취소를 제공한다. 적용한 결과는 되돌릴 수 있고 HTML 저장 후 오프라인에서도 고칠 수 있다. 미리보기 초안은 적용하기 전까지 문서에 반영되지 않는다.
- 활동지는 문서 흐름을 유지하는 영역 순서 변경과 크기 조절을 사용한다. 절대 위치 드래그는 슬라이드에만 제공한다. 도형 내부 점·그래프 데이터의 전용 편집, 셀 병합·분할, 이미지 자르기는 별도 기능이 필요하다. 수식과 그래프의 자동 연동은 제공하지 않는다.

## 빠른 확인

로컬 HTTP로 실제 브라우저에 띄운다. 대표 글/셀 수정 → 필요시 이미지 또는 구조 조작 → HTML 저장 → 다시 열기 순으로 확인한다. 주요 레이아웃과 내용이 보존되어야 한다. 슬라이드는 발표 보기에서 장을 넘기고, 인쇄 시에는 모든 장이 나오는지도 본다.
